# Lab 01：Direct Generation vs Reflection

## Direct Generation prompt

```text
你是一名数据分析助手。
请仅根据下面这张表，列出 2023—2025 年发生的 5 个可核验变化。

要求：
1. 每条结论都引用具体年份和数字；
2. 区分“数据事实”和“基于数据的谨慎描述”；
3. 不引入表外信息；
4. 不推断行业地位、公司估值或买卖建议；
5. 如果表内信息不足，请明确写“无法从表内数据判断”。

输出格式：
- 变化：
- 数据依据：
- 结论边界：

数据表：
[粘贴虚拟公司数据]
```

## 合格判定

对输出逐条检查：

- 数字是否和原表一致？
- 计算方向是否正确？
- 是否真的给出了 5 个变化？
- 每条是否能回到表内找到依据？
- 是否把描述性事实越界写成投资结论？
- 是否明确承认表内无法判断的内容？
