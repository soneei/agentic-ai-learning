## Reflection prompt

```text
请审查下面的 Direct Generation 输出，严格按照检查清单逐条检查。

请完成四步：
1. 标记每条结论为：合格 / 需修订 / 无法判断。
2. 对所有数字重新计算，指出计算错误。
3. 检查是否把表内事实越界成投资判断，或遗漏重要边界。
4. 只修改确实需要修改的地方；如果整体合格，请明确说明不需要强行改写。

检查标准：
- 数字准确
- 依据可追溯到表内
- 事实与推论分开
- 不引入表外信息
- 不给买卖建议
- 不遗漏重要变化

输入：原始数据 + Direct Generation 输出
```

## 学习结论

Reflection 的价值不一定是找出严重错误，也包括：

- 重新计算关键数字
- 把模糊措辞变得可验证
- 检查事实和判断的边界
- 确认整体已经合格时不强行改写
