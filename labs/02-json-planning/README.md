# Lab 02：JSON Planning

## 实验目标

让模型把一个真实业务任务拆成机器可解析的 JSON 计划，再由代码按步骤执行。

本实验仍然先不接真实金融数据，使用虚拟任务验证规划结构。

## 业务任务

> 根据一组公司年度经营数据，生成一份基础研究小结。

## 任务约束

计划至少包含以下步骤：

1. 读取并整理数据
2. 计算关键变化
3. 检查数据和计算结果
4. 生成研究小结
5. 标记无法由表内数据判断的内容

## 本实验要观察什么

- 模型是否能拆出合理步骤
- 每一步是否有清晰的 description
- tool 和 args 是否完整
- 下游代码能否稳定解析 JSON
- 上一步结果能否作为下一步输入
